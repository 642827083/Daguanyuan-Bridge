# Daguanyuan Bridge

Daguanyuan Bridge 是一个 MarginNote 4 插件，用于在学习界面内浏览大观园数学题库和 408 真题，并在脑图题卡与网站题目之间导航。

## 当前功能

- 在独立浮动面板中打开大观园数学和 408 真题页面。
- 面板提供“数学”“408”“设置”三个入口，支持移动、缩放并记忆位置和尺寸。
- 网站视频链接可交给 MN Browser 打开，B 站 BV 链接打开完整桌面视频页，保留分 P 和起播时间；请求发送后自动收起插件，打开视频列表或跳转报错时保持面板显示。需启用 MN Utils 和 MN Browser；视频是否自动播放取决于网站和浏览器行为。
- 使用“上一张”和“下一张”按钮在同级脑图卡片间切换焦点。
- 可选“跨层级切换”，按脑图的深度优先顺序连续前后移动。
- 可选“显示做题进度”，在导航按钮中显示当前卡片的同级位置。
- 可选“显示题型分类”，显示当前卡片直属父节点的标题。
- 浮动按钮支持独立拖动和位置记忆，并根据当前文字自动调整宽度。
- 可绑定数学分类或 408 年份真题，并从选中的脑图题卡定位对应题目。
- 普通数学题卡按网页当前选择的“完整”“严选”或“真题”范围及同级序号定位；导入题卡按保存的题目 ID 定位。
- 数学和 408 分类、年份真题页支持“导入当前题目”，导入当前分类的全部题目，不导入答案。408 知识点导入保留所选分类及全部祖先目录。
- 在“设置 → 题目工具”中独立控制“定位卡片”“添加笔记”和“导入单题”的显示，三个按钮使用一致的白底描边样式。
- “导入单题”将所点击的一道数学或 408 题导入为当前所选卡片的子节点。408 不会题本、不熟题本也支持三个单题工具，不显示“导入当前题目”。
- 整类导入只对当前目标分类查重，单题导入只对所选父节点查重；删除题卡后可以重新导入。再次导入会更新变化的原题卡、跳过相同内容，保留位置、子节点和独立笔记；更新失败保留原内容，原题干内的手动修改会被新版题干覆盖。
- “定位卡片”优先查找当前学习集，未找到时查找其他学习集并自动切换；在“题目工具 → 定位卡片方式”选择“仅定位”或“定位并聚焦”，两种方式均定位居中。有多张匹配题卡时可选择目标。数学错题复测页也支持定位。
- 定位卡片成功后自动收起插件；定位失败或取消时保持面板显示。点击插件图标可恢复原页面。
- 数学和 408 题目页均可将 MarginNote 剪贴板图片添加到网站题目笔记。
- 408 图文导入支持 SVG 题图；普通正文和行内变量保留文字，整段程序保留代码块，公式优先还原为 LaTeX，无法可靠还原时使用公式图片兜底，所有表格转为图片。
- 408 导入可将交集、并集、空集及常用包含关系还原为 LaTeX，减少简单集合公式的图片兜底；再次导入可更新已有题卡。
- 导入结果显示新建、更新、跳过及失败数量，并可复制失败题目的阶段、原因和图像诊断。
- 分类查重与题卡更新需要安装并启用 MN Utils；缺少所需接口时会明确提示。

## 历史

当前正式版本为 1.1.7。1.0.9 曾移除题卡导入等功能；1.1.3 恢复数学当前分类导入；1.1.4 增加 408 图文分类导入、数学与 408 单题导入，以及跨学习集的焦点定位；1.1.5 增加定位方式选择、408 题本工具和已有题卡更新，并完善分类查重、公式、表格与题目定位；1.1.6 改用完整 B 站桌面视频页，补齐简单集合公式还原，并在定位卡片成功或视频跳转请求发送后自动收起面板；1.1.7 完善 408 知识点与真题卷来源定位，保留知识点题目范围及真题单题的年份、题号和模式入口，并补齐数列及大小关系的公式还原。

## 隐私说明

插件不会导出网站 Cookie，不会自动作答或修改题目掌握状态。只有用户点击“添加笔记”时，才会将剪贴板图片提交到当前题目的网站笔记。

## 验证

```powershell
npm test
npm run build
npm run build:release
```

测试构建只生成 `Daguanyuan Bridge Test.mnaddon`。正式构建生成带版本号的安装包；如果同名正式包已经存在，构建会停止并拒绝覆盖。
