# Daguanyuan Bridge

Daguanyuan Bridge 是一个 MarginNote 4 插件，用于在学习界面内浏览大观园数学题库和 408 真题、导入题目，并在脑图题卡和原题之间定位。

当前正式版本：**1.2.5**。最低支持 MarginNote 4.4.5。

## 当前功能

- 数学题库适配新站 `https://math.cxyonly.fans/`，分类更新、题目导入、定位、原题链接及图片笔记沿用当前网页登录状态，兼容已有题卡与绑定中的旧网址。
- 切换脑图或学习集后，题型分类按钮会继续跟随所选卡片刷新父分类名称，无需重新关闭、开启显示。
- 数学全站搜索的题目预览弹窗支持“定位卡片、添加笔记、导入本题”，按弹窗实际题号操作；切题加载期间移除旧入口，避免操作上一题。
- 浮动面板顶部提供居中的“数学／408／导入／设置”白底文字导航，选中项为蓝色文字与平滑移动的短下划线，右侧为无圆底的关闭按钮。顶栏高 44，两侧空白支持拖动和双击重置；面板支持缩放及位置记忆。
- 网页右下角三个点展开一体导入菜单，集中显示“绑定分类”“导入题目”“选题导入”，底栏提供返回、刷新和收起。收起时只保留三个点，无上一页或导入期间会禁用相应导航操作。
- “题型工具”提供题型分类显示、快捷跳转、分类绑定、显示定位题目及分类管理。“定位题目”先唤起面板，再按当前题单、备考科目、脑图题卡所属分类和同级序号查找网站题目，兼容首页侧栏及无侧栏的分类页，可连续跨分类定位；暂时无法识别题单时有限等待并保留页面。“查看原题”在来源分类的练习页中打开真实题目。
- “导入题目”直接导入当前分类的全部题目，不弹出勾选框；“选题导入”保留勾选、确认及“题目／题目＋答案”选项。数学分类导入读取完整分页，保留当前题单、版本、题库范围和备考科目；统一练习网址也能识别当前分类。“选题导入”入口可通过“显示选题导入”开关隐藏。
- “导入本题”支持导入为所选卡片的子节点或同级节点，并记忆位置设置。题干、选项、图片和公式随题目导入。
- 独立导入页支持按题库、范围、数一／数二／数三、分类、年份和题型筛选。点击分类文字或箭头展开、收起，各级分类均可勾选，父分类包含全部后代，重复题目自动去重；408 年份一次只能选择一个。结果和操作区不遮挡左侧筛选。
- 数学导入的分类、题目列表、题目详情和题图通过数学网页使用当前登录状态；导入前请先打开插件“数学”页并登录。登录失效、权限不足或访问验证失败时停止后续读取并提示；限流时按网站返回的等待时间处理。
- 新分类卡片按网站目录顺序插入，保留已有卡片及个人笔记的相对顺序。
- 已有题目重复导入时跳过，保留修改、位置、子节点和笔记；选择“题目＋答案”可补建缺少的答案子卡。答案、解析分别保存为一条评论，仅有其中一项时只建一条；隐藏答案 ID 随第一条正文保存，答案子卡不附带“查看原题”。删除后可重新导入。
- “定位卡片”优先查找当前学习集，未找到时查找其他学习集；支持仅定位或定位并聚焦，多张匹配题卡时可选择。定位成功后收起插件，失败或取消时保留面板。
- “题卡工具”提供已导入题卡修复及数学、408 掌握标记（不熟／不会／掌握）。题卡第一条评论保存题目，第二条保存“查看原题”；原题链接支持原生通知，无需强制安装 MN Utils。点击掌握标记同步对应网站；数学题有有效复测计划时按复测提交。标记前需在插件内打开对应网站并登录。
- “自动折叠查看原题”默认关闭，开启后对新导入和修复后的题卡生效；“查看原题显示”通过弹窗提供“折叠查看原题”和“展开查看原题”，批量处理当前学习集的已导入题卡。“修复题卡格式”提供独立入口，统计后确认修复。评论折叠需要支持相应接口的 MarginNote 版本，缺少接口时提示更新。
- 设置顶部通过悬浮胶囊切换“题型工具、题目工具、题卡工具、关于插件”，选中背景平滑移动，内容可从导航下方滚过；“关于插件”提供版本与作者、重置窗口位置、“插件说明与反馈”、“视频教程”、“诊断日志”和“支持项目”。说明与反馈入口跳转社区帖子，视频教程入口跳转小红书。支持弹窗展示支付宝与微信收款码，适配窗口大小并支持滚动查看。
- “关于插件 → 诊断日志”支持导出纯文本、复制及清空。记录插件与 MarginNote 版本、导入结果、网页通信、图片处理、卡片定位和掌握同步中的错误；最近记录最多保留 2000 条、约 1 MB，重启后保留。
- “题目工具 → MN Browser”默认关闭，B 站视频交由系统打开哔哩哔哩 App；开启后通过 MN Browser 播放并恢复其最小化窗口。视频链接保留分 P 和起播时间，跳转成功后收起插件。
- “添加笔记”默认开启，可在设置中独立切换，用于在数学、408 题目页及数学错题复测页添加剪贴板图片。上一张、下一张、跨层级焦点切换和做题进度已移除，题型工具与定位题目独立保留。
- 408 图文导入支持 SVG 题图、LaTeX 公式还原、公式图片兜底、代码块和表格图片。导入失败时可复制详情，并在再次导入时重试。
- 分类查重和部分题卡工具需要 MN Utils；启用 MN Browser 联动还需安装 MN Browser。缺少所需接口时会提示。

## 隐私说明

插件不会导出网站 Cookie。登录凭据留在网站页面，配置和绑定保存在本地。用户主动点击数学或 408 题卡的掌握标记时，同步对应网站状态；数学题有有效复测计划时提交复测。“添加笔记”会将剪贴板图片上传并保存到对应网站的题目笔记中。

诊断日志仅保存在本机，不自动上传；只选取技术字段，过滤凭据、题目及笔记内容和个人文件路径。排查问题时先复现，再从“设置 → 关于插件 → 诊断日志”导出或复制。日志不能捕获系统崩溃或插件未接管的网站内部错误；保存失败时仍可复制本次内存记录。

文件统一使用 `DaguanyuanBridge` 目录：分类目录、分类绑定和 `logs/diagnostics.json` 保存在文稿目录下，导出临时文件保存在系统临时目录下的 `DaguanyuanBridge/diagnostic-export`。插件不自动迁移旧测试数据，不再读写旧 ID 目录；旧测试日志及废弃的 `math-import-index.json` 可手动删除。现有分类和绑定文件继续使用，开关和窗口位置仍使用原有系统偏好设置键。

## 插件使用风险

- 插件依赖第三方题库网站。网站可调整接口、页面布局、登录要求和访问权限，导致浏览、导入、定位或掌握同步暂时不可用；插件无法保证持续兼容。
- 登录不代表不会触发风控，未登录请求也不代表没有封禁风险。网站可能按账号、IP、请求频率和访问行为实施验证、限流或限制访问，可能涉及账号或 IP 封禁；插件无法保证避免此类限制。
- 进入导入页、切换题库范围或备考科目、选择分类或年份读取题目列表，都可能产生网络请求；并非只有最终点击“导入”才会访问网站。请按实际学习需要分批使用，遇到登录、权限、验证或限流提示时按提示处理，避免连续重复尝试。
- 数学导入使用当前网页登录身份，请确认登录的是预期账号。点击“不熟”“不会”“掌握”会修改对应网站的掌握状态；数学题有有效复测计划时还会记录复测结果并更新计划。
- 导入、格式修复和批量折叠会更改本地学习集。操作前建议备份；网络中断、权限变化或图文解析差异可能造成部分失败或显示差异，请检查导入结果和失败详情，已完成的题卡会保留。

## 验证与构建

```powershell
npm test
npm run build
npm run build:release
```

测试构建生成 `Daguanyuan Bridge Test.mnaddon`。正式构建生成 `Daguanyuan Bridge-v<版本号>.mnaddon`，同名包已存在时拒绝覆盖。版本必须在 `package.json`、`package-lock.json` 与 `src/mnaddon.json` 中一致。

## 问 AI 外部入口

接受经过题目身份校验的 `daguanyuan-bridge?action=ask-ai&...` 链接。数学直接进入本题 `?assistant=1` 页面；408 使用单题入口，等待原有定位器完成后点击网站 AI 辅导按钮，确认界面打开。不会发送问题；关闭面板、切换页面、超时或新请求会停止等待。需配合支持“问 AI”按钮的 Focus Switch。
