# Daguanyuan Bridge 1.0.6

此历史版本缺少独立 Git 提交，src/ 从原始正式安装包完整提取，用于版本存档。package.json 和 package-lock.json 为存档补建的版本元数据，原始开发脚本和测试未保留。

原始安装包见本版本 GitHub Release 附件。

## 导入与错题复测优化

* 错题复测支持定位到已导入的对应脑图题卡。
* 题卡位于其他学习集时，也可以自动打开对应学习集并完成定位。
* 超过 20 道题的分类支持先加载完整题目，再一次性导入，减少导入不完整的情况。
* 在具体题目页面即可导入当前分类，无需先打开分类列表。
* 优化 408 真题题卡显示格式，更完整地保留题干、选项和图片内容。
* 优化题目匹配和重复导入行为，减少误识别或重复创建。
* 未找到对应题卡时显示明确提示，方便确认题目是否已经导入。
