# Daguanyuan Bridge

Daguanyuan Bridge 是一个 MarginNote 4 插件，用于在学习界面内浏览大观园数学题库和 408 真题、导入题目，并在脑图题卡和原题之间定位。

当前正式版本：**1.2.0**。最低支持 MarginNote 4.4.5。

## 当前功能

- 浮动面板顶部提供居中的“数学／408／导入／设置”白底文字导航，选中项为蓝色文字与平滑移动的短下划线，右侧为无圆底的关闭按钮。顶栏高 44，两侧空白支持拖动和双击重置；面板支持缩放及位置记忆。
- 网页右下角三个点展开一体导入菜单，集中显示“绑定分类”“导入题目”“选题导入”，底栏提供返回、刷新和收起。收起时只保留三个点，无上一页或导入期间会禁用相应导航操作。
- “题型工具”提供题型分类显示、快捷跳转、分类绑定、显示定位题目及分类管理。“定位题目”按脑图题卡所属分类和同级序号查找网站题目；导入题卡使用“查看原题”链接打开原题。
- “导入题目”直接导入当前分类全部题目，不附加答案。“选题导入”读取网页当前已加载的题目，支持勾选和“题目／题目＋答案”；该入口可通过“显示选题导入”开关隐藏。
- “导入本题”支持导入为所选卡片的子节点或同级节点，并记忆位置设置。题干、选项、图片和公式随题目导入。
- 独立导入页支持按题库、范围、数一／数二／数三、分类、年份和题型筛选。点击分类文字或箭头展开、收起，只有右侧复选框更改分类选择；结果和操作区不遮挡左侧筛选。
- 已有题目重复导入时跳过，保留修改、位置、子节点和笔记；选择“题目＋答案”可补建缺少的答案子卡。答案、解析分别保存为一条评论，仅有其中一项时只建一条；隐藏答案 ID 随第一条正文保存，答案子卡不附带“查看原题”。删除后可重新导入。
- “定位卡片”优先查找当前学习集，未找到时查找其他学习集；支持仅定位或定位并聚焦，多张匹配题卡时可选择。定位成功后收起插件，失败或取消时保留面板。
- “题卡工具”提供已导入题卡修复及数学掌握标记。题卡第一条评论保存题目，第二条保存“查看原题”；原题链接支持原生通知，无需强制安装 MN Utils。点击掌握标记同步网站，有有效复测计划时按复测提交。
- “自动折叠原题评论”默认关闭，开启后对新导入和修复后的题卡生效；“已导入题卡管理”统一提供修复格式、批量折叠和展开原题评论。评论折叠需要支持相应接口的 MarginNote 版本，缺少接口时提示更新。
- 设置顶部通过悬浮胶囊切换“题型工具、题目工具、题卡工具、关于插件”，选中背景平滑移动，内容可从导航下方滚过；“关于插件”提供版本与作者、重置窗口位置、“插件说明与反馈”、“视频使用教程”、“诊断日志”和“支持项目”。说明与反馈入口跳转社区帖子，视频教程入口跳转小红书。支持弹窗展示支付宝与微信收款码，适配窗口大小并支持滚动查看。
- “关于插件 → 诊断日志”支持导出纯文本、复制及清空。记录插件与 MarginNote 版本、导入结果、网页通信、图片处理、卡片定位和掌握同步中的错误；最近记录最多保留 2000 条、约 1 MB，重启后保留。
- “题目工具 → MN Browser”默认关闭，B 站视频交由系统打开哔哩哔哩 App；开启后通过 MN Browser 播放并恢复其最小化窗口。视频链接保留分 P 和起播时间，跳转成功后收起插件。
- “添加笔记”暂停使用，设置中保持关闭并置灰。上一张、下一张、跨层级焦点切换和做题进度已移除，题型工具与定位题目独立保留。
- 408 图文导入支持 SVG 题图、LaTeX 公式还原、公式图片兜底、代码块和表格图片。导入失败时可复制详情，并在再次导入时重试。
- 分类查重和部分题卡工具需要 MN Utils；启用 MN Browser 联动还需安装 MN Browser。缺少所需接口时会提示。

## 隐私说明

插件不会导出网站 Cookie。登录凭据留在网站页面，配置和绑定保存在本地。只有用户主动点击数学题卡的掌握标记时，才同步网站状态；有有效复测计划时提交复测。

诊断日志仅保存在本机，不自动上传；只选取技术字段，过滤凭据、题目及笔记内容和个人文件路径。排查问题时先复现，再从“设置 → 关于插件 → 诊断日志”导出或复制。日志不能捕获系统崩溃或插件未接管的网站内部错误；保存失败时仍可复制本次内存记录。

文件统一使用 `DaguanyuanBridge` 目录：分类目录、分类绑定和 `logs/diagnostics.json` 保存在文稿目录下，导出临时文件保存在系统临时目录下的 `DaguanyuanBridge/diagnostic-export`。插件不自动迁移旧测试数据，不再读写旧 ID 目录；旧测试日志及废弃的 `math-import-index.json` 可手动删除。现有分类和绑定文件继续使用，开关和窗口位置仍使用原有系统偏好设置键。

## 验证与构建

```powershell
npm test
npm run build
npm run build:release
```

测试构建生成 `Daguanyuan Bridge Test.mnaddon`。正式构建生成 `Daguanyuan Bridge-v<版本号>.mnaddon`，同名包已存在时拒绝覆盖。版本必须在 `package.json`、`package-lock.json` 与 `src/mnaddon.json` 中一致。
