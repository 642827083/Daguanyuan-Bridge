# Daguanyuan Bridge

Daguanyuan Bridge 是一个 MarginNote 4 插件，用于在学习界面内打开大观园数学题库和 408 真题，并提供可拖动的脑图焦点导航按钮。

## 当前功能

- 在独立浮动面板中打开大观园数学和 408 真题页面。
- 面板提供“数学”“408”“设置”三个入口，支持移动、缩放并记忆位置和尺寸。
- 网站要求新窗口打开的视频会继续在当前插件面板中显示。
- 使用“上一张”和“下一张”按钮在同级脑图卡片间切换焦点。
- 可选“跨层级切换”，按脑图的深度优先顺序连续前后移动。
- 可选“显示做题进度”，在导航按钮中显示当前卡片的同级位置。
- 可选“显示题型分类”，显示当前卡片直属父节点的标题。
- 浮动按钮支持独立拖动和位置记忆，并根据当前文字自动调整宽度。

## 已移除功能

1.0.9 不再提供题卡导入、打开选中题目、问 AI、错题复测定位、题目映射和题目元数据存储。升级不会扫描、删除或修改学习集中的既有卡片。

## 隐私说明

插件不会读取或导出网站 Cookie，不会自动作答，也不会修改网站中的掌握状态。用户登录和网页操作均在当前可见面板内完成。

## 验证

```powershell
npm test
npm run build
npm run build:release
```

测试构建只生成 `Daguanyuan Bridge Test.mnaddon`。正式构建生成带版本号的安装包；如果同名正式包已经存在，构建会停止并拒绝覆盖。
