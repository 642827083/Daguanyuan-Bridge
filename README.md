# Daguanyuan Bridge

Daguanyuan Bridge 是一个 MarginNote 4 插件，用于把大观园数学题库和 408 真题当前打开的练习分类导入为脑图卡片，并在题库页面与脑图题卡之间跳转。

## 当前测试范围

- 在插件 WebView 中打开大观园并由用户自行扫码登录。
- 用户打开一个具体练习分类后，点击标题栏的“导入当前分类”。
- 导入前自动触发“加载更多题目”，等待公式和图片完成渲染，并对未完成内容重试一次。
- 插件创建 `Daguanyuan Bridge → 分类 → 题目` 脑图层级；网页能提供完整路径时优先使用网页路径，也可以选中脑图目录后点击“设为目录”覆盖练习根目录。
- 数学和 408 题目统一保存为简化 HTML 题卡，仅保留题干、公式、图片和选项。
- 题目编号、原题地址与分类路径保存在不可见元数据中，不依赖可见题号或 Markdown 链接。
- 重复导入时按题目 ID 更新既有题卡，不重复创建。
- “离线图”默认关闭；开启后会尝试把远程图片嵌入题卡，失败时保留原图片地址并在导入结果中提示。
- 面板固定显示当前页面是否可导入、分类、题目完成度、新建、更新、跳过、未读取和图片失败数量。
- 选中带有题目元数据的卡片后，可使用“打开选中题目”或“问AI”。
- 对没有隐藏链接的旧学习集，可选中题型节点后点击“匹配旧题卡”，题目数量一致时按顺序预览并二次确认；数量不一致时停止批量匹配，可打开具体题目后逐卡关联。
- 已建立关联的旧题卡也支持从大观园错题复测页面定位脑图。

## 题卡与图片说明

- 简化 HTML 题卡主要用于提高脑图预览中的公式、图片和选项可读性，题卡正文不像普通文本评论一样直接编辑。
- 离线图片会增加题卡体积；单张图片超过 6 MB、下载失败或需要额外登录权限时仍使用原网页地址。
- 网页题目尚未加载完成时，插件会导入能够完整读取的题目，并在固定结果区显示未读取数量。

插件不会读取或导出 Cookie，不会自动作答或修改网站掌握状态，也不会后台抓取题库。目录覆盖、离线图片开关和旧题卡映射保存在 MarginNote 文稿目录及原生设置中，不使用 WebView 的 `localStorage` 保存业务数据。

## 验证

```powershell
npm test
npm run build
npm run build:release
```

测试构建只生成 `Daguanyuan Bridge Test.mnaddon`。
正式构建生成带版本号的安装包；如果同名正式包已存在，构建会停止并拒绝覆盖。
