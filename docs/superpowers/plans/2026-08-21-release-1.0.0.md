# Daguanyuan Bridge 1.0.0 发布计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:verification-before-completion before发布完成。

**目标：** 移除工具栏切换提示，统一版本为 1.0.0，生成不可覆盖的正式安装包，并提供社区说明文档。

**方案：** 保留现有面板切换和导入逻辑，仅删除 `togglePanel` 中的 HUD 与诊断日志。新增独立正式构建脚本，从 `src/` 复制插件文件并在正式包已存在时停止；测试包构建继续使用原有命令。

**技术栈：** MarginNote JavaScriptCore、Node.js 内置测试、PowerShell ZIP 打包、Markdown。

---

### 任务 1：移除切换提示

**文件：** `src/WebAddon.js`、`test/import-contract.test.mjs`

- 删除显示/隐藏 HUD 及诊断日志。
- 保留 `panelVisible` 分支和工具栏刷新逻辑。
- 运行导入契约测试。

### 任务 2：同步正式版本

**文件：** `package.json`、`package-lock.json`、`src/mnaddon.json`、`test/package-contract.test.mjs`

- 三处版本统一为 `1.0.0`。
- 保留测试包文件名 `Daguanyuan Bridge Test.mnaddon`。

### 任务 3：新增正式构建

**文件：** `scripts/build-release.js`、`package.json`

- 新增 `npm run build:release`。
- 输出 `Daguanyuan Bridge-v1.0.0.mnaddon`。
- 输出已存在时直接报错，不覆盖原文件。

### 任务 4：编写社区说明

**文件：** `Daguanyuan Bridge 1.0.0 社区介绍.md`

- 参考 MoMo Import 社区文档结构，说明功能、使用步骤、目录结构、图片题目和限制。
- 增加 `Ver 1.0.0` 更新记录。

### 任务 5：验证发布包

- 运行 `npm test`、`node --check` 和 `npm run build`。
- 运行 `npm run build:release`。
- 检查正式包清单、版本和同名包覆盖保护。
