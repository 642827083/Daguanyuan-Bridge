# 题卡分类与复测导航设计

## 目标

让大观园导入题目继续落在完整的前两级分类下，题卡保存对应练习复测地址，并避免原题链接遮挡题卡正文。

## 方案

页面采集器从当前练习页地址生成每道题的 URL，只保留当前页的查询参数并设置该题的 `questionId`。原生导入器优先使用题目 URL，并为 `practiceId=329` 补回 `高等数学 -> （一）极限` 前缀。题卡正文使用隐藏 Markdown 注释保存 URL，选中题目读取逻辑同时兼容新旧两种链接格式。面板按钮显示为“问AI”，当前行为仍是打开选中题目的练习复测页。

## 边界与兼容

- JavaScriptCore 侧不使用浏览器 `URL` 对象或 `fetch`。
- 旧题卡中的 `/math/questions/{id}` 可见链接继续可识别。
- 没有题目链接时继续显示明确错误。
- 不修改版本号、正式包或社区说明文档。

## 验证

- 采集测试确认练习 URL 含当前题目 `questionId`。
- 导入测试确认 329 的完整分类路径和隐藏 URL 标记。
- 选中题目测试确认隐藏标记和旧可见链接均可读取。
- 面板契约测试确认按钮文字为“问AI”。
- 运行完整 Node 测试、JS 语法检查和测试包构建。
