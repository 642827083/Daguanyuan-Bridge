# 导入交互统一：大观园选题页

日期：2026-10-06。参考疾风劲草的网页内导入弹窗，补齐大观园的选题操作。三个插件继续独立安装；本次修改大观园数学与 408，不宣称三个插件已全部统一。

## 入口与行为

- 在支持的数学题型页、408 知识点与年份题目页右下角只显示“选题导入”，与疾风劲草一致。收藏题本不显示选题入口；题目内原有单题入口保留。
- 弹窗的“目标学习集”只显示学习集名称，不附加插件目录、分类路径或所选卡片；读取不到名称时显示“当前学习集”，不显示内部 ID。
- 只有“选题导入”打开网页勾选弹窗，默认全选。顶部显示来源、目标学习集和全选/清空，中间显示逐题复选框与两行摘要，底部固定数量、导入内容与提交按钮。空选不能提交；顶部关闭按钮在运行中兼作停止入口。
- 原有“导入当前题目”和题内“导入单题”恢复直接导入与原生进度、结果提示，不经过选题弹窗，也不导入答案。
- 单题按当前可见题目识别，沿用设置中的子节点或同级节点位置。分类导入沿用当前学习集下的分类层级。
- 数学先读完当前范围的全部分页，再提供选择；408 根据原始题目索引准备所选题。确认后只下载、转换和写入所选题目，不改用另一批列表。
- 读取或待确认时取消不会写卡；运行中停止会阻止后续写入，保留已完成题卡。网页路由、插件页和目标学习集切换时中止旧任务。
- 选题弹窗支持“题目／题目＋答案”，默认仅题目。“题目＋答案”读取网站可用的答案和解析，连同其中的图片保存；答案读取失败或完全缺失时该题明确失败，不假装成功。
- 相同内容跳过，导入内容变化时更新。答案和解析写入题卡的导入评论；切换为仅题目重新导入会移除该评论内的导入答案，独立笔记和子节点保留。导入按钮说明提示评论内手动修改可能被覆盖。
- 成功、部分失败与中断均显示可查看和复制的结果。网页结果显示异常时保留原生详情作为兜底。

## 实现

- `web/src/DaguanyuanImportPage.js` 与 CSS 管理实际网页界面；样式以疾风劲草导入弹窗为基准。
- 前端通过 `web/src/lib/mnBridge.js` 发命令，`src/WebBridgeCommands.js` 分发，`src/DaguanyuanImportSelection.js` 管理任务和确认。
- 题目摘要每批 100 条传入网页；选择通过原生读取每批 250 个 ID，避免大量 ID 塞入 URL。原生校验数量、成员与重复项，再按原题序导入。
- 数学、408 和单题写入器沿用原有图像转换、学习集建卡与查重更新逻辑，增加所选 ID 与取消检查。
- `scripts/build-web.js` 从网页源码生成 `src/web-dist/DaguanyuanImportPageScript.js`。测试/正式构建均先生成资源，不手改生成目录。
- `scripts/preview-import.js` 可启动本地预览，使用同一份前端脚本和样式；题库与原生回执使用明确标记的演示数据，不连接或写入 MarginNote。

## 接口依据

已查阅 [MN Utils](https://mnaddon.craft.me/mnapi)、[JavaScriptCore 运行时](https://mn-docs.museday.top/reference/js-runtime/)、[全局对象](https://mn-docs.museday.top/reference/global/global-variables/) 与 [UIWebView](https://mn-docs.museday.top/reference/uikit/uiwebview/)。系统二选一确认接口不提供勾选列表，采用项目既有网页注入与 WebView 委托通信。原生定时使用 NSTimer，网页 DOM 仅在网页脚本中使用。

## 真机验收

1. 安装测试包，重新打开插件数学/408 题目页，检查右下角选题入口与勾选弹窗。
2. 只勾选两题，确认学习集中仅这两题建卡；分别验证数学跨页题目与 408 非连续题号。
3. 检查单题子节点/同级位置、图片、重复导入更新与笔记保留。
4. 取消选题、运行中停止、切换网页与学习集，检查无后续误写且已完成计数正确。
5. 真机缩放窗口、旋转设备，确认触摸操作和 WebView 字体布局。浏览器预览与自动化不替代此项真机验收。
